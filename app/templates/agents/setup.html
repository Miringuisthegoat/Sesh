Installation steps

About 5 minutes
  1. Download the installer for Windows 10/11, 64-bit.
  2. Run it. No administrator rights are needed. The installer is not code-signed yet, so Windows SmartScreen may warn: choose More info, then Run anyway. Tick "Start Sesh Agent automatically when I sign in".
  3. Generate an enrolment token on the Office & printer page{% if not office %} (set up the office first){% endif %}. It is shown once, works one time and expires after {{ token_hours }} hours.
  4. Connect. On first launch enter this server address and the token:
    {{ server_url }}
  5. Choose the printer to make available, then check the Office page shows the computer as Connected.

Good to know

  • The agent only makes outbound HTTPS connections: no router changes, VPN or public IP.
  • It uses printers already installed in Windows; it never installs drivers.
  • SumatraPDF is needed for printing and is not bundled. See docs/AGENT.md.
  • "Sent to printer" means Windows accepted the job, not that paper came out.
